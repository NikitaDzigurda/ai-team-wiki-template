## Командная AI Wiki

Память проекта `{{PROJECT}}`: `{{WIKI}}/projects/{{PROJECT}}/`.

### Начало задачи

1. Прочитай `{{WIKI}}/projects/{{PROJECT}}/index.md`, `{{WIKI}}/context/index.md` и `{{WIKI}}/standards/index.md`, если их ещё нет в контексте.
2. Если сабмодуль отсутствует: `git submodule update --init --recursive`.
3. Ищи уже известное: `{{PY}} "{{WIKI}}/scripts/wiki.py" recall "<ключевые слова>"`. `--all` включает другие проекты этой wiki.
4. Открывай только нужные записи и сверяй их с текущим кодом. Для большой задачи можно создать план через `new-spec`.

### По ходу работы

| Что сохранить | Куда |
|---|---|
| Проверенный факт, указание, ссылка, ограничение | `memory/` через `new-memory` |
| Решение с альтернативами | `decisions/` через `new-adr` |
| Ловушка и способ её обойти | `gotchas.md` |
| Запуск, окружение, проверки | `overview.md` |
| Устройство кода / соглашения | `architecture.md` / `conventions.md` |
| Общий контракт или вопрос команды | `{{WIKI}}/context/` со ссылкой на ADR |

Используй `wiki-save` или выполняй команды CLI вручную. Не записывай секреты, персональные данные и сведения, которые попросили не сохранять. Указывай источники; предположение не является фактом. Обновляй существующие записи, а не создавай дубли.

### Завершение задачи

Выполни `wiki-session-end` или вручную сохрани полезный итог через `new-session`, обнови память, затем:

```sh
{{PY}} "{{WIKI}}/scripts/wiki.py" reindex
{{PY}} "{{WIKI}}/scripts/wiki.py" validate
```

Коммит и push выполняются по задаче пользователя и правилам команды: `sync` создаёт локальный коммит памяти текущего проекта, `sync --push` дополнительно публикует. Общий контекст и стандарты коммитятся отдельно. При сабмодуле нужно также сохранить новый указатель в основном репозитории.

Формат записей: `{{WIKI}}/standards/memory/memory-format.md`. Если skills или хуки недоступны, следуй этому протоколу вручную. Для первой настройки проекта используй `wiki-init`.
