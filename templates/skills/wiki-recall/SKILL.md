# Поиск по памяти

Прочитай `{{WIKI}}/projects/{{PROJECT}}/index.md`, затем выполни:

```sh
{{PY}} "{{WIKI}}/scripts/wiki.py" recall "<ключевые слова>"
```

Поиск требует наличия всех слов в документе; при пустой выдаче сократи запрос. `--all` ищет во всех проектах этой wiki, `--full` показывает все совпавшие строки (не полный документ).

Открой релевантные файлы, связанные ADR и `gotchas.md`. Сверь выводы с текущим кодом. Устаревшую запись исправь, прежде чем опираться на неё. Сообщи найденное со ссылками, если это помогает текущей задаче, и продолжай работу.
