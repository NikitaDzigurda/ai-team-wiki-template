# Стиль текстов

Для wiki, README и документации.

- **Язык:** русский. Термины, имена файлов, команды, идентификаторы, slug — на английском. Slug в kebab-case.
- **Коротко.** Сначала главное. Без вводных («В данном разделе…»), без канцелярита, без маркетинга.
- **Конкретно.** Пути, команды, имена переменных — в `бэктиках`. Команды — блоком кода, готовым к копированию.
- **Даты абсолютные:** `2026-10-14`, не «на прошлой неделе».
- **Заголовки:** `#` — один на файл, дальше `##` и `###`.
- **Списки** — для перечислений, **таблицы** — для сопоставлений (тип → куда писать). Связный текст, если важна логика рассуждения.
- **Ссылки** между файлами wiki — относительные markdown-ссылки.
- **Неуверенность** помечай явно: «не проверено», «предположительно».
