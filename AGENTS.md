# AI Team Wiki: инструкции для работы с шаблоном

Этот репозиторий содержит переносимую командную wiki. Начни с `README.md`.

- `projects/_template/` — пустые формы. Не добавляй в шаблон данные конкретного продукта, команды или клиента.
- `context/` — заготовки общего контекста; заполняются в отдельной wiki команды.
- `standards/` — исходные соглашения, которые команда адаптирует под себя.
- `templates/consumer/` — управляемые блоки инструкций и конфиги хуков.
- `templates/skills/` — переносимые skills; установщик подставляет пути и имя проекта.
- `scripts/` — Python 3.9+, только стандартная библиотека.

Сохраняй маркеры `agent-wiki:start/end` и `auto:index:start/end`: по ним обновляются только управляемые блоки. Установщик должен сохранять пользовательский текст и сторонние хуки. Хуки не должны ломать сессию при ошибке. Не записывай секреты и персональные данные.

После изменений выполни:

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

При создании wiki команды замени этот файл при необходимости её собственными правилами. Коммиты, push и правила веток определяются задачей пользователя и политикой команды; сам шаблон не даёт разрешения на публикацию.
